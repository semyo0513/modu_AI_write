# 📘 모두의 AI 융합 글쓰기 웹앱 (고도화 수행평가 & 생기부 에디션)

> **학교 현장 맞춤형 과정 중심 글쓰기 수행평가 시스템**  
> 학생별 작성 시간 측정 · 수정 기록 로그(Replay 타임라인) · **루브릭 기반 AI 1차 자동 채점** · **생활기록부(과세특) 일괄 생성** · **블라인드 익명 동료평가(상호 피드백)** 지원

---

## 🌟 주요 기능 및 고도화 항목

### 1. 📝 생활기록부(과세특) 초안 단일 & 일괄 생성 (신규)
- **과정 중심 데이터 기반 자동 서술:**
  - 학생의 **총 작성 시간**, **수정 및 퇴고 횟수(버전 수)**, **AI 질의응답 이력**, **본문 핵심 논거**를 종합 분석.
  - 교육부 훈령 및 학교생활기록부 기재 요령(글자 수 제한, 금지어 배제, 표준 종결어미 `~함`)에 부합하는 과세특 문안을 단일 및 **제출 완료 학생 전체 일괄 생성**.
- **나이스(NEIS) 호환 CSV 다운로드:**
  - 생성된 과세특 문안을 브라우저에서 즉시 검토·편집할 수 있으며, 나이스 양식(학년, 반, 번호, 이름, 과세특) CSV로 일괄 내보내기 지원.

### 2. 🎯 루브릭 기반 AI 1차 자동 채점 (Teacher Copilot) (신규)
- **루브릭 기준별 점수 및 판정 근거 도출:**
  - 교사가 설정한 평가 기준(배점, 설명)을 바탕으로 AI가 학생 글을 정밀 분석.
  - 항목별 가채점 점수뿐만 아니라 **판정 근거(본문 발췌 문장)**와 **종합 분석 코멘트**를 자동 제시.
- **단일 학생 즉석 채점 & 전체 학생 일괄 자동 채점:**
  - 학생 개별 평가 모달 내 `[🤖 AI 1차 자동 채점 실행]` -> `[✓ 점수 폼에 일괄 적용]`
  - 대시보드 테이블 상단 `[⚡ AI 1차 일괄 자동 채점]` 버튼으로 수십 명의 학생을 한 번에 가채점.

### 3. 👥 블라인드 익명 동료평가 (상호 피드백) ON/OFF (신규)
- **교사 제어권 (활성화 / 비활성화 토글):**
  - 과제 설정에서 동료평가를 켜거나 끌 수 있으며, 피드백 최소 글자수 설정 가능.
- **블라인드 상호 피드백 프로세스:**
  - 수행평가 최종 제출을 완료한 학생에게 동료평가 메뉴가 열림.
  - 같은 반 친구들의 글 중 무작위 1~2편이 **학번과 이름이 완전히 가려진 익명(동료 학생 작품 #1, #2)**으로 배정.
  - **칭찬한 점**, **보완할 점(질문)**, **추천 스티커(👍 훌륭해요, 💡 참신해요 등)**를 남겨 협력적 메타인지 글쓰기 역량 신장.
  - 학생은 자신의 글에 도착한 친구들의 익명 피드백을 실시간 열람 가능.

### 4. ⏱️ 학생별 작성 시간 & 수정 기록(Revision Logs) 완벽 보존
- **시간 지표 2종 측정:** 총 작성 소요 시간 + 실제 집중 타자 시간 (초 단위)
- **버전별 수정 스냅샷:** 단락 변경, 임시 저장, 제출 시 버전(v1, v2, v3...) 자동 누적.
- **Replay 타임라인 슬라이더:** 초안부터 최종본까지 시간에 따른 글의 발전을 슬라이더로 재생·비교.

### 5. 🤖 교육적 AI 글쓰기 코칭 (대필 원천 방지)
- AI가 대신 글을 써주지 않고, 질문과 반론을 유도하는 소크라테스식 코칭 프롬프트 적용.
- 학생과 AI 간의 질의응답 이력이 서버에 투명하게 보존되어 교사가 확인 가능.

## 🚀 5분 빠른 배포 가이드 (Step-by-Step)

### [1단계] 구글 스프레드시트 및 GAS 백엔드 배포 (3분)

1. [Google 스프레드시트](https://sheets.new) 생성 후 상단 **[확장 프로그램] -> [Apps Script]** 클릭.
2. 기존 코드를 지우고 [`Code.gs`](file:///c:/Users/경남교육청/Desktop/모두의%20AI%20융합%20글쓰기%20웹앱/Code.gs) 전체 코드를 복사하여 붙여넣기.
3. 상단 함수 선택에서 **`setupDatabase`**를 선택하고 **[실행]** 클릭 (권한 승인).
   - `Admins`, `Tasks`, `Students`, `Writings`, `RevisionLogs`, `ChatLogs`, `PeerReviews` 7개 시트 자동 생성.
4. 우측 상단 **[배포] -> [새 배포]** 클릭:
   - 유형: `웹 앱(Web App)`
   - 다음 사용자로 실행: `나(Me)`
   - 액세스 권한: `모든 사용자(Anyone)` ⚠️ **필수 확인!**
5. 생성된 **웹 앱 URL** 복사.

### [2단계] GitHub Pages 배포 (2분)

1. [GitHub](https://github.com)에 새 Repository 생성 후 [`index.html`](file:///c:/Users/경남교육청/Desktop/모두의%20AI%20융합%20글쓰기%20웹앱/index.html) 파일 업로드.
2. **[Settings] -> [Pages]**에서 Branch를 `main`, `/ (root)`로 설정하고 저장.
3. 배포된 페이지로 접속하여 우측 상단 **[⚙️ 서버 URL 설정]** 아이콘 클릭 후 웹 앱 URL 붙여넣기.
